# ThronesRide: Game of Thrones FiveM Resource

ThronesRide is a FiveM resource that brings the world of Game of Thrones to your server. This resource includes dragon riding mechanics, unique jobs, and various commands to enhance your gameplay experience. Keywords: FiveM, Game of Thrones, dragon riding, jobs, commands.

## Install

1. Download the ThronesRide resource from the GitHub repository.
2. Extract the downloaded file into your FiveM server's `resources` directory.
3. Add `ensure ThronesRide` to your `server.cfg` file to start the resource automatically when the server launches.

## Use

1. **Dragon Riding**:
   - Spawn a dragon: `/spawnDragon`
   - Dismount the dragon: `/dismountDragon`
   - Activate fire breath: `/fireBreath`

2. **Jobs**:
   - Set your job: `/setJob [jobName]`
   - Available jobs: knight, archer, mage
